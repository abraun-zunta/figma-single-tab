Figma Single Tab

Opens every Figma link in the tab where that file is already open — just like the desktop app. Existing tab jumps to the new location, the duplicate tab closes.

The instant, no-reload jump uses Figma's plugin API, which only turns on after you run any plugin once in a tab. Until then, leave this off to never reload (the link just opens in a new tab), or turn it on to reload the existing tab so the link still lands in one tab.
Tip: run any Figma plugin once in a file to enable instant no-reload jumps for that tab.
